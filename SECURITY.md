# Security Policy

## Supported Versions

We provide security updates for the latest major version of DynamicWallpaperEngine.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in DynamicWallpaperEngine, please do NOT create a public issue.

Instead, please send a report to the security maintainers with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge receipt of your vulnerability report within 48 hours and provide detailed updates regarding remediation.
