# 安全性政策

## 支援的版本

我們會為 DynamicWallpaperEngine 的最新主要版本提供安全性更新。

| 版本    | 是否支援            |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## 報告漏洞

如果您在 DynamicWallpaperEngine 中發現安全性漏洞，請**不要**建立公開的 Issue。

相反地，請將報告發送給安全性維護人員，並包含：
- 漏洞描述
- 重現步驟
- 潛在影響

我們將在 48 小時內確認收到您的漏洞報告，並提供關於修復措施的詳細更新。
