# 貢獻者公約 行為準則 (Contributor Covenant Code of Conduct)

## 我們的承諾

身為社群的成員、貢獻者和領導者，我們承諾無論參與者的年齡、體型、可見或不可見的失能、種族、性徵、性別認同與表現、經驗等級、教育背景、社經地位、國籍、外貌、族群、宗教、性身分與性傾向為何，都致力於讓參與我們社群的每個人，都能享有免於騷擾的體驗。

我們承諾，將以促進一個開放、熱情、多元、包容且健康的社群之方式進行互動。

## 我們的標準

有助於為我們的社群創造正面環境的行為範例包括：

* 對他人展現同理心與善意
* 尊重不同的意見、觀點與經驗
* 給予並優雅地接受具建設性的回饋
* 承擔責任並向受到我們錯誤影響的人道歉，並從經驗中學習
* 關注什麼不僅對我們個人最好，而是對整個社群最好的事

不可接受的行為範例包括：

* 使用性暗示語言或圖像，以及任何形式的性關注或性暗示
* 挑釁 (Trolling)、侮辱或貶損的評論，以及針對個人或政治的攻擊
* 公開或私下的騷擾
* 在未經明確許可的情況下，發布他人的私人資訊，例如實體地址或電子郵件地址
* 其他在專業環境中可合理視為不適當的行為

## 執行責任

社群領導者有責任澄清和落實我們對可接受行為的標準，並將對任何他們認為不適當、具威脅性、冒犯性或有害的行為採取適當且公平的糾正行動。

## 適用範圍

本行為準則適用於所有社群空間，也適用於個人在公共空間正式代表社群時的場合。
